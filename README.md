## Description
A simple Flask application with a single `/health` endpoint, built to demonstrate an end-to-end CI/CD pipeline using GitHub Actions.

## Endpoint
- `GET /health` → returns `{"status": "ok"}`

## Tech Stack
- Python (Flask)
- Docker
- GitHub Actions

## Status
🚧 Under development — CI/CD pipeline being built by the DevOps team.
